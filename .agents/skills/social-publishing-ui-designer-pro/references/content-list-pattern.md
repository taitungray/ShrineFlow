# Content List Pattern

推薦：

- Search
- Status filter
- Platform filter
- Account filter
- Date
- Campaign
- Clear filters
- Result count

Columns:

- Content
- Platform
- Status
- Schedule / Published time
- Owner
- Updated
- Actions

Bulk actions 只提供真正安全且高頻的操作。

不要把：
Delete / Publish Now / Retry / Archive
全部直接放成 row icons。
