# Social Publishing QA Matrix

| Area | Happy | Edge | Failure |
|---|---|---|---|
| Draft | save | rapid edit | save fail |
| Media | upload | reorder | processing fail |
| Review | approve | edit-after-approve | permission fail |
| Schedule | future | timezone | invalid time |
| Publish | success | multi-platform | partial fail |
| Retry | recover | repeated | duplicate risk |
| Calendar | render | reschedule | save fail |
| Permission | allowed | role change | forbidden |
