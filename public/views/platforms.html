📘 簡易教學：3 步驟快速拿到 Facebook 金鑰與粉專 ID ›
🔗 1. 開啟 Meta App 後台 🔗 2. 開啟 Graph 測試工具 🔗 3. 開啟 Token 延長工具
1 建立 Meta 應用程式（只需做一次）
  1. 前往 Meta for Developers ➔ 點右上角 建立應用程式 ➔ 類型選擇 企業 (Business)。
  2. 在「使用案例」勾選：管理粉絲專頁的所有內容（若要發 IG 順便勾選「管理 Instagram 訊息與內容」）。
  3. 建立完成後，到左側選單點 使用案例 ➔ Pages API ➔ 權限 ➔ 確認並新增：
    • pages_manage_posts（發布與排程貼文）
    • pages_show_list（列出管理的粉專）
    • pages_messaging（收件匣回覆私訊）
    • pages_manage_metadata（即時 Webhook 通知）
    • business_management（企業帳號管理）
2 取得粉專 ID 與 Access Token（三動搞定）
  1. 打開 Graph API 測試工具 ➔ 最上方「Meta 應用程式」選剛剛建立的 App。
  2. 確認加入核心發布權限：在右側「權限 (Permissions)」清單中確認已勾選（若沒有請按 Add a Permission 搜尋加入）：
    • pages_manage_posts（發文必備）
    • pages_show_list（取得粉專清單）
    • pages_messaging（收件匣私訊）
    • pages_manage_metadata（Webhook 通知）
    • business_management（企業管理）
  3. 點擊右上方藍色按鈕 產生存取權杖 (Generate Access Token) ➔ 在跳出視窗中登入並勾選授權你的粉絲專頁。
  4. 將中間的網址輸入框換成這段代碼（點擊全選複製）：
    me/accounts?fields=id,name,access_token
    然後按右邊的 提交 (Submit) 按鈕。
  5. 在下方回應的內容中，找到你的粉專名稱：
    • 把 "id": "123456789..." 的數字複製 ➔ 貼到上方的 Facebook Page ID 欄位。
    • 把 "access_token": "EAA..." 的長字串複製 ➔ 貼到上方的 Page Access Token 欄位。
  6. 點擊本頁下方的 💾 儲存此品牌 FB 連線 ➔ 🧪 測試連線，顯示綠色粉專名稱就代表成功連線了！🎉
3 換成永久不過期 Token（建議設定）
  1. 打開 Token Debugger 延伸工具。
  2. 把步驟 2 第一次產生的用戶 Token (EAA...) 貼進去 ➔ 點 除錯 ➔ 往下拉點擊藍色按鈕 延伸存取權杖 (Extend Access Token)。
  3. 將延長後的 Token 貼回 Graph 測試工具 右側 ➔ 重新按一次 提交 (Submit) ➔ 複製粉專最新的 access_token 覆蓋回本頁儲存即可！
✨ 永久 Token 驗證：放進 Token Debugger 查看若顯示 Expires: Never（從不），代表永遠不會過期！
🚨 發文後粉絲看不到？ 請到 Meta 應用程式後台 ➔ 點你的 App ➔ 右上角將 開發中 (Development) 切換為 上線 (Live)，所有人就能看見貼文了！

📘 簡易教學：如何取得 Instagram 憑證 ›
  1. 先決條件：IG 帳號需為 專業／商業帳號，並已在手機 IG 設定中綁定此品牌的 Facebook 粉專。
  2. 加開權限：在 Graph 測試工具 右側「權限」清單中，確認已勾選 instagram_basic 與 instagram_content_publish（若無請按「Add a Permission」搜尋加入），並重新產生權杖。
  3. 查詢 User ID：網址輸入 me/accounts?fields=id,name,instagram_business_account ➔ 按「提交」。
  4. 填入資料：
    • 把 instagram_business_account.id 的數字貼到 Instagram User ID。
    • Access Token 直接貼上已包含 IG 權限的 Page Access Token 即可。

📘 簡易教學：如何取得 Threads 憑證 ›
  1. 在同一個 Meta App 中，使用案例勾選 存取 Threads API。
  2. 前往 Threads 授權說明，透過 Threads 登入取得專用 Token（開頭通常為 THQVJ...）。
  3. 對 Threads API 查詢 graph.threads.net/me 取得您的 Threads 數字 ID 貼入上方 Threads User ID 即可。
