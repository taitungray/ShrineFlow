ShrineFlow 隱私政策

生效日：2026-08-18　·　營運者：ShrineFlow

ShrineFlow 是給品牌小編使用的社群發布工作台。用來撰寫、排程並發布內容到你管理的 Facebook 粉專、Instagram 與 Threads。本政策說明我們處理哪些資料、為什麼處理，以及你如何要求刪除。

1. 我們服務的對象

本服務的使用者是獲授權的操作員（小編、管理員），不是粉專粉絲。粉絲在 Facebook／Instagram／Threads 上的公開瀏覽，由 Meta 各自的政策規範。

2. 我們收集與處理的資料

  • 帳號資料：登入用的電子郵件、顯示名稱、角色與工作階段。
  • 平台連線：你主動貼上的粉專 ID、Instagram／Threads 使用者 ID，以及 Page／User Access Token。Token 只存在伺服器，並加密保存。
  • 內容資料：文案、素材、排程時間、發布狀態、模板與活動紀錄。
  • 平台回傳資料：為了發文、排程與客服回覆，我們會向 Meta Graph API 讀取粉專名稱、貼文發布狀態，以及粉專私訊的必要欄位。
  • AI 文案：你輸入的主題與參考文字會送到 Google Gemini，用來產生草稿。請勿把不該外傳的個資放進提示。
  • 營運紀錄：發布嘗試、錯誤紀錄與系統健康狀態，用於除錯與可靠度，會有保留上限。

3. 我們如何使用資料

  • 讓你登入並管理品牌與帳號連線。
  • 依你的指示建立、排程、發布、取消或重試貼文。
  • 顯示發布狀態與粉專收件匣，方便回覆。
  • 維護服務安全、除錯與防止濫用。

我們不把這些資料賣給第三人，也不拿粉絲個資做廣告再行銷。

4. 我們與誰分享

  • Meta：依你點擊的發布／排程／回覆，把內容與必要權杖送到 Facebook、Instagram、Threads。
  • Google：Firebase 登入與雲端資料庫、Gemini 文案產生、Cloud Run 託管。
  • Cloudflare：公開媒體檔案存放（R2）。

上述服務各有自己的隱私政策。除了提供本服務所必需，我們不另作商業分享。

5. 保存期間

帳號、品牌連線與內容會保存到你刪除該筆資料、解除連線，或要求我們刪除為止。錯誤與發布紀錄依系統上限定期清理。平台 Token 在你更新或撤銷後即停止使用。

6. 你的權利

  • 在後台檢視、修改品牌設定與內容。
  • 隨時解除 Facebook／Instagram／Threads 連線，並在 Meta 撤銷 App 授權。
  • 要求匯出或刪除你的工作台資料。步驟見 資料刪除說明。

7. 安全

平台 Token 與 API 金鑰以伺服器端加密與機密管理保存，不放進前端原始碼。傳輸使用 HTTPS。沒有絕對安全，若發現外洩會通知受影響的操作員。

8. 兒童

本服務不提供給 13 歲以下兒童使用，也不刻意收集兒童個資。

9. 政策更新

若處理方式有實質變更，我們會更新本頁並修改生效日。繼續使用即表示你知悉更新後的政策。

10. 聯絡我們

資料查閱、更正或刪除：請用你登入 ShrineFlow 的電子郵件來信，主旨註明「隱私權／資料刪除」，並寫明品牌名稱。我們會在合理期間內處理。
