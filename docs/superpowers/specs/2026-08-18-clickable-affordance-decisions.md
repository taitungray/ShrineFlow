# 可點元素 afforance 決定（2026-08-18）

問題：全站很多動作長得像純文字（無邊框、透明底），使用者不知道能點。

## 最後決定

階層維持四級，不把所有動作做成主色大按鈕（會搶 CTA）。

| 級別 | 用途 | 長相 | 處理 |
|---|---|---|---|
| Primary / Save / Dark | 主動作：新增、產生、儲存、排程、確認 | 實心底＋對比字 | 不改 |
| Secondary | 次動作：儲存連線、建立模板、批次 | 品牌色字＋品牌混色邊框＋卡片底 | 邊框加對比 |
| Quiet control | 重新整理、今天、登出、取消、測試、卡片列動作 | **有邊框＋卡片底**，不再透明 | `btn-text` / `btn-test` / `btn-icon` / `content-card-action` / `group-action-link` |
| Inline link | 說明文字裡的跳轉 | 品牌色＋底線 | `field-link` 預設底線 |

規則：

1. **能點就要看得出是控件。** 幽靈按鈕（無邊、透明）停用。
2. **說明裡的連結用底線**，不要做成按鈕，避免跟 CTA 搶。
3. **分段頁籤（radio-pill）維持現況**，本來就有邊框與選中態。
4. **觸控**：獨立按鈕 ≥ 44px；內容卡片列動作桌面 36px、手機 44px。
5. **危險動作**（立即發布、刪除）保留紅色字，但仍加邊框，不靠純文字。

## 不這樣做

- 不把「重新整理／今天／登出」升級成 Primary。
- 不改平台名稱規則（畫面平台名用 Facebook，粉專只出現在帳號／設定說明）。這輪只處理能點的長相。

## 驗證

改的是全域按鈕 CSS。本機 F5 看：頂欄登出、內容列「封存／隱藏／複製」、日曆「今天」、幫助「查看全部」。
